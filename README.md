# Quarterly Sales Analysis in C++

This is a simple C++ console application that allows the user to enter monthly sales data for four quarters. The program can calculate quarterly averages, yearly average sales, find the highest and lowest sales values, and display all sales data in a table format.

## Features
- Enter sales data for 4 quarters
- Calculate quarterly averages
- Calculate yearly average
- Find maximum and minimum yearly sales
- Print sales data in formatted table
- Menu-driven program

## Language Used
C++
